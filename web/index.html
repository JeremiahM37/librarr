Search Preferences

Filter non-English results

When enabled, books with non-English titles are hidden from English-focused sources. Multilingual sources (Flibusta, Z-Library) always show all results.

Download Behavior

How imported files reach the library. Move takes the payload out of the download folder, so the torrent can no longer seed even if you keep it. Hardlink and Copy leave the payload in place so seeding continues; hardlinks need the download folder and the library on the same filesystem, and fall back to a copy when they are not. On Automatic you never have to think about it: keeping torrents hardlinks them, removing torrents moves them.

Remove torrents after import

When enabled, the torrent is removed from the download client after its files are imported. Disable it to keep seeding: the torrent's record stays in the client, and on Automatic its files stay in the download folder too — hardlinked into the library rather than moved, which is what seeding actually needs.
